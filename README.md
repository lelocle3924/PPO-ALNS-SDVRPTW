# PPO-ALNS-SDVRPTW
Apply PPO-ALNS framework to solve Site Dependent VRP with Time windows case study.

This is the Capstone Project conducted at International University, VNU HCM from Sep 2025 to Jan 2026, equally contributed to by Le Xuan Bao Loc IELSIU22057, Nguyen Hai Dang IELSIU22014 and Vu Duc Minh IELSIU22063.

The data is from a case study of a last mile delivery problem, which is formulated as a Site Dependent Vehicle Routing Problem with Time Windows.

The solution method is PPO-ALNS, a framework referenced from Wang, Z., Cui, Q., Tan, B., Yang, X., Zhou, W., & Huang, X. (2025). Reinforcement learning-guided adaptive large neighborhood search for vehicle routing problem with time windows. Journal of Combinatorial Optimization, 50(4), 1-24.
